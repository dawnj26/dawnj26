## A bit about me

I spend most of my time building mobile and full-stack applications — the kind of work where you get to think through architecture *and* obsess over user experience at the same time.

Right now I'm deep into advanced backend systems and cloud deployment, but the thing that really excites me lately is the intersection of AI and everyday software. I built an AI-powered craft recommendation app (more on that below) and it reminded me just how much fun it is to ship something that feels a little magical.

## 🚀 Things I've built

### CraftMate — *AI-powered craft companion*
Started as a fun idea: what if you could photograph the random materials lying around your house and get actual project ideas from them? It turned into a full mobile platform with personalized craft suggestions, an AI recommendation engine, and a marketplace for handmade products.

**Stack:** Flutter · Firebase · AI integration · GitHub Actions (CI/CD)

---

### Hotel Management System — *Full-stack operations platform*
Built a reservation and hotel operations system with role-based access, an analytics dashboard, and booking automation. Focused heavily on making the backend clean and the workflows intuitive for actual hotel staff.

**Stack:** Laravel · Inertia.js · React · MySQL
